## Si `npx` n'est pas disponible

Les guides sont tous dans `guides/` (un fichier Markdown par sujet). Cherche directement dedans,
par exemple : `grep -ril "dialog" .claude/skills/modern-web-guidance/guides`, puis lis le guide trouvé.

## Mettre à jour

Recopier le dossier `skills/modern-web-guidance` du dépôt source à la place de celui-ci.
