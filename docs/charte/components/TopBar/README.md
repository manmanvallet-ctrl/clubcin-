# Bandeau de navigation

Le bandeau en tête de chaque écran : un aplat `band` (bordeaux profond) avec la marque en Georgia et les rubriques. C'est la signature de la charte, reprise en tête des cartes importantes (voir Carte film).

- Classes : `.top`, `.brand`, `nav a`, `nav a.active`.
- Marque et rubrique active en `band-ink` (crème) ; rubriques inactives en `band-muted`.
- La rubrique active est une pastille crème avec le texte en bordeaux.
- Sur mobile, la navigation passe sous la marque et défile horizontalement.
