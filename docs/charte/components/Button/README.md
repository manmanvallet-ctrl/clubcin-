# Bouton

Un seul bouton principal (rouge rideau) par écran, pour l'action pour laquelle l'écran existe ; tous les autres sont neutres.

- `button` : neutre, fond `surface`, filet `line`, bord `accent` au survol.
- `button.primary` : aplat `accent-fill`, texte `accent-ink`, gras.
- `button.done` : étape terminée, en `ok`, toujours avec ✓.
- `button.link` : action secondaire ou suppression douce (« Retirer »), soulignée.
- Libellé : un verbe, majuscule initiale seulement.
