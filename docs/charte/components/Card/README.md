# Carte

Le conteneur de base : une notion, un atelier, un réalisateur, un indicateur.

- `.card` : fond `surface`, filet `line`, arrondi `radius-lg`, 18px de marge intérieure. Pas d'ombre.
- `.row` en haut : intitulé (`.intitule`, bordeaux) ou méta à gauche, tag à droite.
- Indicateur : `.big` (Georgia, chiffres tabulaires) et `.bar` de progression en `accent-fill`.
- `.card.tile` : carte entièrement cliquable, bord `accent` au survol.
