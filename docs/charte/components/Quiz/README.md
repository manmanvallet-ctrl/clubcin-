# Quiz

Questions à choix multiple, une à la fois, 640px de large maximum.

- Choix : boutons alignés à gauche, 10×14px de marge intérieure.
- Après réponse : bonne réponse en `ok` avec ✓, mauvaise en `ko` (orange) avec ✗ ; les autres choix sont désactivés.
- Le retour explique toujours pourquoi, en une phrase.
