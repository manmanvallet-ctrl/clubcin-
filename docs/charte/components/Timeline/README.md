# Frise chronologique

La colonne vertébrale du module Histoire du cinéma.

- Rail vertical `line`, points ronds : vides (`muted`) pour les périodes à voir, pleins `accent-fill` pour les périodes lues (`li.read`).
- Années en `accent`, chiffres tabulaires ; titre de période en Georgia (style `periode`).
- Chaque période est un bouton qui déplie sa carte de contenu.
