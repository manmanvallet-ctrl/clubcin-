# Tags et chips

Les tags indiquent le type d'activité ou le niveau ; les chips servent de filtres.

- `.tag` : fond `accent-soft` rosé, texte `accent-soft-ink`, coins `radius-sm` (pas en pilule, comme sur la carte film).
- `.tag.l3` (Expert) : aplat `accent-fill`, texte `accent-ink`. Le niveau est toujours écrit en toutes lettres.
- `.chips button` : filtres en pilule ; le filtre actif passe en aplat `accent-fill`.
- Un seul filtre actif à la fois par rangée.
